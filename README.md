# Shortest Clue RuneLite Plugin

![image](https://img.shields.io/endpoint?url=https://api.runelite.net/pluginhub/shields/installs/plugin/shortest-clue)
![image](https://img.shields.io/endpoint?url=https://api.runelite.net/pluginhub/shields/rank/plugin/shortest-clue)

A RuneLite plugin that integrates with the Shortest Path plugin to find and display the shortest path to your current clue scroll location.

- Automatically detects your current clue scroll step.
- Calculates and sends the shortest path to the clue location using the Shortest Path plugin.
- With "Require items" on, asks Shortest Path to bring the spade for dig clues and the items for emote clues, visiting a bank when necessary.
- With the [Dude, Where's My Stuff?](https://runelite.net/plugin-hub/show/dude-wheres-my-stuff) plugin installed, an emote clue's items aren't asked for when they're already in its STASH unit.
